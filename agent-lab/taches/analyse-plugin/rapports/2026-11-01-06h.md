## 1. Consolidation : routage et modèles des agents dupliqués
- Constat : le routage (quelle tâche, quel agent) et les modèles (Haiku 5.5 / Opus 5.5, effort) sont écrits dans `skills/cu-workflow/SKILL.md` (tableau Agents + paragraphe), `agents/*.md` (description et frontmatter) et `README.md`. Un changement de modèle demande 3 éditions.
- Proposition : les `agents/*.md` sont la source de vérité. Le skill ne garde qu'une phrase de renvoi et la règle de coût ; le tableau perd la colonne Modèle ; le README ne cite plus les modèles.
- Bénéfice : une seule source, plus de dérive.
- Effort : faible.

## 2. Amélioration : détection robuste du `git commit` dans le hook de livraison
- Constat : `hooks/verify.mjs` filtre avec `/\bgit\s+commit\b/` et lit la branche de `projectRoot`. `git -C dir commit` et `git -c k=v commit` ne sont pas reconnus (la vérification est contournée silencieusement) et la branche ne tient pas compte du `-C`.
- Proposition : regex tolérant les options globales git (`git(\s+-[cC]\s+\S+|\s+--\S+)*\s+commit`), et branche lue dans le répertoire visé par `-C` s'il existe.
- Bénéfice : la vérification de livraison ne se contourne plus par accident.
- Effort : faible.
